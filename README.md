## Running the Notebooks Locally

The `requirements.txt` file in this folder contains the Python libraries needed to run the English and French notebooks locally.

### Install the Requirements on Windows

Open PowerShell in the `OSC-repo` folder and run:

```powershell
python -m pip install -r .\requirements.txt
```

### Install the Requirements on macOS

Open Terminal in the `OSC-repo` folder and run:

```bash
python3 -m pip install -r ./requirements.txt
```

### Open a Notebook in VS Code

1. Install the **Python** and **Jupyter** extensions for VS Code.
2. Open the `OSC-repo` folder in VS Code.
3. Open the English or French `.ipynb` file you want to use.
4. Select **Kernel** or **Select Kernel** in the notebook toolbar.
5. Choose the Python environment where you installed `requirements.txt`.
6. Run the notebook cells in order.

### Optional: Use JupyterLab

JupyterLab is included in `requirements.txt`, but it is not required if you are using VS Code or another notebook-compatible editor.

On Windows, open PowerShell in the `OSC-repo` folder and run:

```powershell
python -m jupyter lab
```

On macOS, open Terminal in the `OSC-repo` folder and run:

```bash
python3 -m jupyter lab
```
