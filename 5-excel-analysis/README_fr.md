# Leçon 5 : Analyse de fichiers Excel — Données ouvertes de l’Ontario

Ce dossier contient les fichiers de soutien de la leçon 5 pour importer des données Excel avec `pandas` et les visualiser avec `plotly`.

## Source des données de l’Ontario

Les fichiers utilisés en classe dans ce dossier sont dérivés de la source suivante :

- Information sur les écoles et données démographiques sur les élèves : <https://data.ontario.ca/fr/dataset/school-information-and-student-demographics>

## Fichiers de ce dossier

- `notebook_fr.ipynb` : carnet de travail en français.
- `data_fr.xlsx` : fichier Excel adapté pour le carnet en français.
- `data_en.xlsx` : fichier Excel correspondant en anglais.
