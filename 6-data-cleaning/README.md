# Lesson 5 - Data Cleaning (CSV Examples)

This folder contains beginner-friendly CSV files for Lesson 5 data-cleaning practice.

## Files

- `data1_en.csv`: Missing values (`NaN`) and duplicate rows.
- `data2_en.csv`: Extra metadata lines before the real header row (`skiprows` practice).
- `data3_en.csv`: Additional mixed-quality sample for extension/reference.
- `data1_fr.csv`: French counterpart of `data1_en.csv`.
- `data2_fr.csv`: French counterpart of `data2_en.csv`.
- `data3_fr.csv`: French counterpart of `data3_en.csv`.
- `notebook.ipynb`: Main student assignment notebook (submission artifact).
