# Leçon 3 : Fondements des carnets Jupyter

Ce dossier contient les fichiers de la leçon 3 destinés à la livraison de l’OSC.

## Fichiers

- `demo-notebook_fr.ipynb` : carnet de démonstration pour la présentation guidée par l’enseignante ou l’enseignant.
- `assignment-notebook_fr.ipynb` : carnet de travail permettant aux élèves de s’exercer à utiliser les cellules Markdown et les cellules de code.
- `examples/arcade-leaderboard-notebook_fr.ipynb` : exemple d’un flux de travail présenté sous forme de carnet.
- `examples/arcade-leaderboard-dense-script.py` : même exemple présenté sous forme de script Python compact. Le code sert de référence comparative et ne contient pas de texte pédagogique à traduire.

## Ordre d’utilisation recommandé

1. Commencer par le plan de leçon de la leçon 3.
2. Présenter `demo-notebook_fr.ipynb` aux élèves comme démonstration interactive.
3. Demander aux élèves de réaliser `assignment-notebook_fr.ipynb` afin de mettre en pratique la création d’un carnet.
4. Utiliser les fichiers du dossier `examples/` pour comparer un flux de travail dans un carnet à un script compact.
5. Utiliser la fiche de travail de la leçon 3 pour consolider les apprentissages et favoriser la réflexion.
